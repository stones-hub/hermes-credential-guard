## 产品目标

Credential Guard 0.4.2 在保留单一工具 `http_credential_request` 与单一 HTTP binding 的前提下，将 `target.scheme` 从“仅 `https`”扩展为精确接受小写 `http` 或 `https`。两种 scheme 共用固定目标、方法、路径、credential、inject、审批、防偷换、禁代理、禁重定向、超时、响应上限与统一结果脱敏；差异仅为 HTTPS 使用 TLS 校验，HTTP 明文传输并在审批中固定警告。

不新增 CIDR、`network_policy`、`allow_insecure_http` 或第二套执行器。否决的「统一拦截全部模型外发」方案（`docs/R8-Hermes统一模型外发拦截接口-落地方案.md`）仍禁止执行；本里程碑 R8 仅指 HTTP/HTTPS 统一凭证请求。
